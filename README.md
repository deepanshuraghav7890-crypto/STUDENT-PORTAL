# Student Portal

A web-based Student Portal built to manage student information through separate Admin and Student login functionality.

## Features

- Admin Login
- Student Login
- Student Details Management
- Add, View, and Manage Student Information (where implemented)
- Data Storage and Retrieval
- User-Friendly Interface
- Client-Server Architecture

## Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Data Storage
- Excel-based data storage

## Project Structure

- `client/` – Frontend application
- `server/` – Backend API and data management

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/deepanshuraghav7890-crypto/STUDENT-PORTAL.git
```

### 2. Run the Frontend

```bash
cd client
npm install
npm start
```

### 3. Run the Backend

Open a separate terminal:

```bash
cd server
npm install
node src/index.js
```

## Project Purpose

This project was created to practice full-stack web development, frontend and backend integration, API communication, authentication, and student data management.
